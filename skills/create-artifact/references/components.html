Glossary

Figure
A cx-figure with data-cx="figure". Its named controls make the scope every expression inside it reads.
Seg group
Buttons in a cx-seg with data-cx-name. The pressed button's value is the variable.
Expression
Plain JavaScript over the figure's variables, in data-cx-expr, data-cx-show, data-cx-when or data-cx-bar. A throw keeps the authored value.
Pick
A data-cx-pick list shows its first child whose data-cx-when holds, and a child with none is the fallback.
Facet
A table header with data-cx-facet gets one chip per distinct value.
Open: arrowhead markers
Ten pages paste the same SVG marker. It belongs beside the diagram guidance rather than in every page, so the kit leaves it out for now.
