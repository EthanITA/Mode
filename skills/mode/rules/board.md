## The board

- Any turn that does autonomous work runs on a visible task board, kept with the task tools: the first edit, command or multi-step plan puts it up before the work, not after. Turns that only read to answer, and turns ending in a question, are exempt.
- The board tracks the whole topic rather than the current turn. Unfinished scope stays visible as open items, items are added as work surfaces, and pending work that stopped mattering is dropped.
- The item being worked is in progress, what comes next is pending, and a box is ticked only when the work is done and verified. A ticked box is a receipt, and receipts are never deleted.
- A fully ticked board asserts the topic is done, so decompose until every condition of done is its own item, delivery included. Delivery closes against the project's own stated bar, read rather than assumed.
